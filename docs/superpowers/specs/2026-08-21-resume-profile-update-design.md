## 生成、验证与发布

1. 检查 Markdown 结构、时间线和关键数据是否与简历一致。
2. 运行 `npm run clean` 和 `npm run build`。
3. 确认 `public/2099/12/31/about-me/index.html` 已生成并包含百度实习、TAR-FL 和新状态。
4. 运行 `npm run deploy` 发布到 GitHub Pages。
5. 仅提交本次设计说明和个人页源码，不包含 `.claude` 等无关本地改动；将源码推送到 `origin/source`。

## 异常处理

- 若 Hexo 构建失败，先定位构建日志并只修复与本次 Markdown 更新相关的问题。
- 若部署成功但线上页面暂未刷新，保留成功的部署记录并提示 GitHub Pages 缓存可能存在短暂延迟。
- 若源码分支或部署分支推送失败，不重复覆盖或重置仓库，保留本地提交并报告具体错误。
